## Termos

| TERM     | Papel                    |
| -------- | ------------------------ |
| TERM-001 | Entidade central         |
| TERM-005 | Solicitante              |

## Fluxo lexical candidato

```text
Registrar solicitação → (opcional) anexar evidência → decidir → converter (se aprovada)
```

## Distinções obrigatórias

- Solicitação ≠ OS (TERM-002)
- Solicitação ≠ pedido comercial (TERM-012) sem validação
- Canal (TERM-036) é CAPABILITY_ONLY
